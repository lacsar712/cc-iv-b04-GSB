# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

顶栏有「同箱最弱串」专页：上方选箱号与截止钟点，中间列各串最近办结开路电压与最弱标记，下方口径只读。选定箱或改截止钟点会连带触发重算，差值与最弱标记只认重算返回，不在画面上偷填。箱内还有未办结读数时不出最弱标记、不填假数；落在所选钟段外的读数本次不算；截止钟点与重算捆在同一次提交里，少一边都报 400。扫描员可选箱号报送，观察员只能看已报送结果。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/boxes` | 列出已有箱号（登录即可） |
| POST | `/api/box-weakest/recalc` | 仅扫描员；`{box_no, cutoff}` 缺一不可，重算并留存报送 |
| GET | `/api/box-weakest/latest?box_no=` | 该箱最近一次报送结果（登录即可） |

最弱串口径：截止钟点前每串取最近一次办结扫描的开路电压，基准为箱内最高值，差值最大者为最弱串；有未办结读数则本次不出标记。
